# This log was renamed on 1 September 2026

The project this log belongs to was called **EDR** — Election Defense
Reporting. It is now called **ElectionLog**, and on 1 September 2026 the
repositories holding it were renamed to match.

Nothing about the record changed. No anchor was rewritten, no snapshot was
altered, no commit was rebased. Only the address changed.

This file exists because it has to. An archive whose entire claim is that
it cannot be quietly altered should not also be an archive that quietly
moves. Somebody arriving in five years with an old URL is entitled to find
out what happened from the log itself rather than from a redirect that may
no longer exist.

## What changed

| | before | after |
|---|---|---|
| Codeberg (primary) | `codeberg.org/munsdev/edr-transparency-log` | `codeberg.org/munsdev/electionlog-transparency-log` |
| GitHub (mirror) | `github.com/munsdev/edr-transparency-log` | `github.com/munsdev/electionlog-transparency-log` |

Both hosts issue redirects from the old names. Those redirects are a
convenience and are not part of the record — this file is.

## What did not change

- **Every commit before this one.** Same hashes, same history, same order.
  A clone taken before the rename and a clone taken after it have identical
  histories; `git log` proves it without trusting anything written here.
- **Every RFC 3161 timestamp token** published in this log. They cover
  chain heads, not repository names, and no name appears in what was
  stamped.
- **Every report reference beginning `EDR-`.** A report's public reference
  is part of what it was sealed with, so those cannot be reissued without
  breaking the seal on the report they belong to. Reports filed from
  1 September 2026 onward begin `EL-`. Two prefixes in one archive is the
  correct outcome of a rename done honestly, not an inconsistency to be
  tidied away later.

## Why this was done now rather than left alone

Every report in the archive at this date is a test report, and the archive
is not yet open to the public. Renaming later would mean a redirect
standing between a reader and the proof, permanently. Renaming now costs
nothing but this file.
